6. Methodology

The following analysis checks were performed:

  • Atom structure (A1–A6): required-box presence, moov/mdat ordering, ftyp brand consistency, track-structure integrity, unexpected box types, trailing data after the last box.
  • Edit list (E1–E4): edit-list presence, entry count, empty-edit detection, timing consistency.
  • Chunk offsets & sample tables (O1–O9): offset-table type, monotonicity, gap analysis, mdat alignment, video/audio interleaving (O5), sample-table completeness, mdat payload accounting, stco/stsc chunk-count agreement, cross-table sample-count consistency.
  • Metadata (M1–M5): timestamp consistency, timescale and frame-rate consistency, duration consistency, codec-parameter consistency, post-processing software signatures.
  • Device-class profile (D0–D3): container-signature similarity scoring against the device profile database, including layout-vs-profile contradiction.

7. Limitations

  • Device signature matching is based on known device profiles. Unusual or undocumented devices may produce atypical but authentic container structures.
